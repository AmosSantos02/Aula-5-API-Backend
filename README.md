Sobre o Projeto

Este é um projeto backend de exemplo desenvolvido utilizando Node.js com o framework Express, hospedado no Render. Ele fornece um endpoint para realizar operações CRUD (Create, Read, Update, Delete) sobre um conjunto de dados simples.

Tecnologias Utilizadas

Node.js

Express

Render (Hospedagem)

Funcionalidades

GET: Retorna todos os registros

POST: Cria um novo registro

PUT: Atualiza um registro existente

DELETE: Remove um registro

Estrutura Básica

a typical express server with routes for CRUD operations organized in a simple structure.
